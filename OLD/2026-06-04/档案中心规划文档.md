# 项目需求文档：高中化学学生智能追踪系统 (Chem-Track AI)

## 1. 项目概述
**项目名称**：Chem-Track AI  
**目标用户**：一位高中化学教师  
**核心痛点**：传统学生记录方式（Excel/纸质）效率低、数据非结构化、难以实时追踪学生状态变化、缺乏可视化反馈。  
**解决方案**：构建一个基于 Web 的智能系统，支持**自然语言输入**，利用 **LLM (大语言模型)** 自动解析、打分、提取事件，经过**人工复核**后存入数据库，并提供**可视化仪表盘**和**Excel 导出**功能。多次写入新指标覆盖旧指标。

---

## 2. 核心功能模块

### 2.1. 学生基础画像管理 (Student Profile)
*   **功能描述**：建立和维护学生的基础档案。
*   **数据字段**：
    *   `id`: 唯一标识符
    *   `name`: 姓名
    *   `class`: 班级
    *   `student_id`: 学号
    *   `gender`: 性别
    *   `labels`: 动态标签数组 (Array of Strings)，支持自定义、增删改。例如：`["#逻辑强", "#敏感", "#基础弱"]`。
    *   `created_at`: 创建时间
    *   `updated_at`: 最后更新时间

### 2.2. 自然语言输入与 LLM 处理引擎 (NLP & LLM Engine) —— **核心模块**
*   **输入接口**：提供文本输入框（支持语音转文字接入）。
*   **处理流程**：
    1.  **接收输入**：教师输入非结构化文本，如：“今天张三测验氧化还原全对，但上课走神。李四作业没交，情绪低落。”
    2.  **LLM 解析**：
        *   **实体识别**：识别文本中涉及的学生姓名。
        *   **意图分类**：判断内容属于“课堂表现”、“测验成绩”、“心理状态”或“家校沟通”。
        *   **自动打分**：根据预设评分标准，对涉及的 A/B/C 三个维度进行打分 (0-5分)。（维度 D 考勤由系统自动计算，不由 LLM 打分。）
        *   **事件提取**：提取关键事件（如“测验全对”、“情绪低落”）。
        *   **原始归档**：保留原始输入文本，用于追溯。
    3.  **输出草案**：生成数据结构 (`DraftRecord`)。

### 2.3. 人工复核与确认 (Human-in-the-Loop)
*   **功能描述**：教师对 LLM 生成的数据进行审核。
*   **交互逻辑**：
    *   llm处理完后再由教师批量复核。
    *   展示原始输入文本。
    *   展示 LLM 建议的分数、标签变更、提取的事件。
    *   llm先进行一轮复核，主要看逻辑是否通顺、数据是否异常，然后将复核结果和提取结果统一交给教师最后复核。
    *   教师可以**修改**分数或**删除**错误事件。
    *   点击“确认”后，数据正式写入数据库；点击“放弃”则丢弃本次记录。



### 2.4. 量化指标与预警系统 (Metrics & Alerts)
*   **四个核心维度**：
    1.  **A. 学习目标达成 & 课堂测验** (Academic Performance)
    2.  **B. 精神面貌 & 课堂纪律** (Behavior & Discipline)
    3.  **C. 课后任务** (Homework & Tasks)
    4.  **D. 考勤** (Attendance) —— **系统自动计算**，不由 LLM 或教师手动打分。
*   **维度 D 考勤计算公式**：`分数 = 5 × (出勤次数 / 当前学期累计课次)`
    *   结果四舍五入到整数，取值 0-5。
    *   例如：本学期已上 10 次课，某学生出勤 8 次 → D = 5 × 8/10 = 4 分。
*   **评分标准**：0分 (极差) 至 5分 (优秀)。
*   **预警逻辑**：
    *   若某维度分数 < 2分，或连续3次记录 < 3分，触发**预警**。
    *   系统在 Dashboard 首页高亮显示预警学生，并推送 LLM 生成的“关注建议”。

### 2.5. 学期与课次管理 (Semester & Session)
*   **功能描述**：管理学期和每节课的课次记录，为考勤计算提供基础数据。
*   **学期**：
    *   教师可创建学期，如 "2024-2025学年第一学期"。
    *   每个学期记录开始日期和结束日期。
*   **课次**：
    *   教师每次上课后记录一次课次（自动递增课次数）。
    *   课次归属于某个学期，包含上课日期。
    *   当前课次 = 该学期下已记录的课次总数。
*   **操作**：
    *   「上课」按钮：记录今天的课次，学期课次数 +1。
    *   课次列表：查看/删除历史课次记录。

### 2.6. 考勤管理 (Attendance)
*   **功能描述**：记录每名学生在每节课次的出勤情况，自动计算维度 D 考勤分数。
*   **记录方式**：
    *   在快速评分卡片中，每次课次自动展示考勤勾选框。
    *   默认全员出勤，教师只需勾掉缺勤的学生。
*   **自动计算**：
    *   每次课次记录后，系统自动重算所有学生的维度 D 分数。
    *   公式：`D = ROUND(5 × 出勤次数 / 当前课次总数)`
*   **数据追溯**：
    *   可在学生详情页查看每节课的出勤状态（出勤/缺勤）。

### 2.7. 快速评分卡片 (Quick Score Cards)
*   **功能描述**：卡片式批量评分，替代 NL 录入覆盖日常高频场景。
*   **交互逻辑**：
    1.  教师选择班级 + 日期。
    2.  系统展示该班所有学生的评分卡片网格。
    3.  每张卡片包含 A/B/C 三个维度的 0-5 分快捷按钮 + 可选备注框。
    4.  默认每人初始 3 分，教师只需调整有变动的学生。
    5.  顶部提供「批量设置」：一键将整班某维度设为同一分数。
    6.  底部「全部提交」→ 一键覆写当天 DailyMetric，备注自动生成 Event。
*   **与 NL 录入的关系**：
    *   快速评分：适合课后批量扫一遍全班打分（覆盖 80% 日常场景）。
    *   NL 录入：适合描述复杂情况、心理状态、家校沟通等（覆盖 20% 复杂场景）。
    *   两者统一写入 DailyMetric，仪表盘/预警/导出通用。

### 2.8. 家校沟通记录 (Parent Communication Log)
*   **功能描述**：专门记录与家长的互动。
*   **处理逻辑**：
    *   LLM 识别到“家长”、“电话”、“微信”等关键词时，自动归类为“家校沟通”。
    *   记录沟通时间、对象、主要内容摘要。
    *   归档至该学生的独立页面。

### 2.9. 数据可视化仪表盘 (Dashboard)
*   **个人视图 (Student Detail)**：
    *   **雷达图 (Radar Chart)**：展示当前四个维度 (A/B/C/D) 的得分分布。
    *   **趋势折线图 (Line Chart)**：展示过去30天各维度分数的变化趋势。
    *   **事件时间轴 (Timeline)**：按时间倒序展示关键事件、沟通记录和原始日志。
    *   **考勤明细**：列出每节课次的出勤/缺勤状态。
*   **班级视图 (Class Overview)**：
    *   班级平均分概览（含 A/B/C/D 四个维度）。
    *   **预警列表**：按紧急程度排序的需要关注的学生名单。

### 2.10. 数据导出 (Export)
*   **功能描述**：支持将数据导出为 Excel (.xlsx)。
*   **导出结构**：
    *   **Sheet 1: 学生档案** (姓名, 班级, 学号, 标签, 当前状态)
    *   **Sheet 2: 每日指标历史** (日期, 学生ID, 维度A, 维度B, 维度C, 维度D, 操作人)
    *   **Sheet 3: 关键事件日志** (日期, 学生ID, 事件类型, 事件描述, 原始文本)
    *   **Sheet 4: 家校沟通记录** (日期, 学生ID, 沟通对象, 内容摘要)
    *   **Sheet 5: 考勤记录** (日期, 学生ID, 课次号, 出勤状态)
*  按选择时间进行导出。

## 3. LLM 交互规范 (Prompt Engineering)

### 3.1. System Prompt 设计
LLM 必须遵循以下指令进行解析：

```text
你是一名资深的高中化学教师助手。你的任务是根据教师的自然语言输入，提取学生数据并生成结构化记录。

【评分标准】(0-5分连续整数分值，请根据文本表现从0到5中选取最匹配的分数)
维度A (学习目标&测验): 
- 5分: 测验优秀/满分，主动提问，目标明确。
- 4分: 测验良好，较积极参与，目标较清晰。
- 3分: 测验及格，被动参与，目标一般。
- 2分: 测验勉强及格，参与度低，目标模糊。
- 1分: 测验明显退步，基本不参与，缺乏目标。
- 0分: 测验不及格，无目标，放弃状态。

维度B (精神面貌&纪律):
- 5分: 精神饱满，专注度高，遵守纪律。
- 4分: 状态较好，多数时间专注，纪律良好。
- 3分: 状态一般，偶尔走神，基本守纪。
- 2分: 状态欠佳，频繁走神，偶有违纪。
- 1分: 精神不振，纪律松散，多次违纪。
- 0分: 精神萎靡，严重违纪，干扰他人。

维度C (课后任务):
- 5分: 作业/笔记高质量完成，积极答疑。
- 4分: 作业完成质量较好，主动订正。
- 3分: 作业按时提交，质量一般。
- 2分: 作业偶有缺交或敷衍，需催促。
- 1分: 作业经常缺交/拖延，质量差。
- 0分: 作业缺交、抄袭或严重拖延。

注：维度 D (考勤) 由系统根据公式 `5 × 出勤次数 / 当前课次` 自动计算，不由 LLM 打分。

【输出格式】
请返回 JSON 格式数据，包含以下字段：
- students: Array of objects
  - name: string (学生姓名)
  - scores: object { A: number, B: number, C: number } (仅当文本中明确提及该维度表现时才更新，否则为 3分)
  - events: Array of strings (提取的关键事件，如 "测验全对", "上课睡觉")
  - communication: object (仅当涉及家长沟通时存在) { type: string, summary: string }
  - raw_text: string (原始输入文本，用于归档)
- alert_suggestion: string (如果检测到异常，给出简短的关注建议，否则为空字符串)

【注意事项】
1. 如果文本中未提及某维度，不要随意打分，保持 3分平均分，并在llm复核报告中提及。
2. 维度 D (考勤) 不由你打分，scores 对象中不包含 D。
3. 保持客观，基于文本事实判断。
4. 如果涉及多个学生，分别列出。
