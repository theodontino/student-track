# Chem-Track AI 系统设计说明

> **版本**: v0.9.0 | **日期**: 2026-06-04
> **目标用户**: 高中化学教师
> **核心工作流**: NL 输入 → LLM 解析 → LLM 自审 → 教师复核 → 写入数据库

---

## 1. 系统架构

```
前端 (Next.js)  ──REST API──>  API 层 (Route Handlers)
  6 个页面                         21 个端点
                                    │ Prisma Client
                              SQLite (8 张表)
                                    │
                              外部 LLM (DeepSeek)
                              parseInput + reviewParsed
```

**依赖链**: 页面 → `fetch(/api/...)` → Route Handler → `prisma.*` → SQLite  
**LLM 链**: `/api/input/parse` → `lib/parser.ts` → `lib/prompts.ts` → `lib/llm.ts` → DeepSeek API

## 2. 数据模型摘要

> 完整定义、已知问题、优化方案见 **[数据结构文档](./数据结构文档.md)**。

```
Semester ──< ClassSession ──< Attendance >── Student
                                      │
Student ──< DailyMetric                │
Student ──< Event                      │
Student ──< Communication              │
                                      │
DraftRecord (独立，按 name 匹配 Student)
```

| 表 | 核心唯一约束 | 说明 |
|---|---|---|
| Student | `studentId @unique` | 基础档案 |
| **SessionMetric** | `@@unique([studentId, sessionId])` | v0.4: 每课次独立评分；v0.9: 改名 |
| Event | — | 关键事件，v0.9: 绑定 sessionId |
| Communication | — | 家校沟通，v0.9: 绑定 sessionId |
| DraftRecord | — | NL 待复核草案 |
| Semester | — | 学期管理 |
| ClassSession | `code @unique` (YYYYMMDDNN) | 课次编码体系 |
| Attendance | `@@unique([sessionId, studentId])` | 考勤记录 |
| *SessionMetricHistory* | 无唯一约束（追加模式） | v0.5: 评分变更归档，v0.9: 改名 |

| 路由 | 页面 | 数据来源 |
|---|---|---|
| `/` | 仪表盘（预警+班级概览） | `GET /api/alerts` |
| `/students` | 学生管理（CRUD+导入） | `GET/POST /api/students` |
| `/students/[id]` | 学生详情（雷达图+趋势+事件） | `GET /api/students/[id]` |

| `/report` | 报告生成（日报+反馈+批量导出） | `POST /api/report/daily` 等 |

### 3.2 核心业务规则

**评分维度**:
| 维度 | 名称 | 打分方 | 范围 |
|---|---|---|---|
| A | 学习目标达成 & 课堂测验 | 教师 / LLM | 0-5 |
| B | 精神面貌 & 课堂纪律 | 教师 / LLM | 0-5 |
| C | 课后任务 | 教师 / LLM | 0-5 |
| D | 考勤 | 系统自动计算 | 0-5 |

**考勤公式**: `D = ROUND(5 × 出勤次数 / 当前学期总课次数)`  
重算时机：创建课次后、考勤变更后、删除课次后。

**预警规则**:
| 条件 | 等级 |
|---|---|
| 任一维度最新得分 < 2 | 🔴 红色 |
| 任一维度连续 3 次 < 3 分 | 🟡 黄色 |

**NL 处理链**:  
`教师文本 → parseInput(temp=0.3) → reviewParsed(temp=0.2) → DraftRecord(pending) → 教师复核确认/修改 → DailyMetric + Event + Communication`

**数据写入规则**:
- `DailyMetric`: 按 `(studentId, sessionId)` upsert，同课次覆盖；scoreD 更新到最新一条 metric
- `Event`: 追加模式，不覆盖
- LLM 只输出文本中提及的学生，未提维度 score 为 `null`；D 不由 LLM 打分

### 3.3 API 路由一览

| 方法 | 路由 | 功能 |
|---|---|---|
| GET/POST | `/api/students` | 学生列表 / 创建 |

| GET/POST | `/api/quick-score` | 按课次查询评分 / 批量提交 |
| GET | `/api/alerts` | 仪表盘（概览+预警+班级平均） |
| GET/PUT | `/api/attendance` | 考勤查询 / 批量更新 + 重算 D |
| GET/POST | `/api/semesters` | 学期列表 / 创建 |
| PUT/DELETE | `/api/semesters/[id]` | 更新 / 删除学期 |
| POST/DELETE | `/api/semesters/[id]/session` | 创建课次 / 删除课次（级联+重算） |

| POST | `/api/report/daily` | 按课次生成班级日报（LLM） |
| POST | `/api/report/feedback` | 单人家校反馈（按课次或时间段） |
| GET/POST | `/api/report/feedback-batch` | 批量反馈：POST SSE 流式逐人生成 → GET 下载缓存 Excel |

## 4. 已知限制

1. **NL 解析仅精确姓名匹配**，不支持模糊匹配
2. **LLM 无重试机制**，超时/格式错误直接报错
3. **单教师版**，无多用户/权限体系

> 数据模型层面的已知问题见 **[数据结构文档 §2](./数据结构文档.md#2-表结构详情)**。
