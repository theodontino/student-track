## 1. ER 关系图

```
Label ←── StudentLabel ──→ Student
                    ↑
Class ──< Student ──< Attendance >── ClassSession ──< Semester
                                      │
                                      ├──< SessionMetric
                                      ├──< Event
                                      └──< Communication

SessionMetricHistory (追加归档)
DraftRecord (独立表，含 studentId/sessionCode)
SystemLog (独立表，记录关键操作)
WorkHistory (独立表，长期保存页面工作快照)
```

**关键设计决策**:
- v0.10: `Class` 表，`Student.classId` + `ClassSession.classId` FK → Class
- v0.11: `SystemLog` 表，记录评分/预警/删除等操作，90 天自动清理
- v0.12: `Operator` 枚举 → Prisma enum，编译期类型约束
- v0.12: `SessionMetricHistory` `@@index([studentId])` / `@@index([metricId])`
- v0.13: `Label` + `StudentLabel` 关联表替代 `Student.labels` JSON
- v0.14: `WorkHistory` 保存快速评分、NL、报告、反馈、导出页面快照；无自动过期
- SessionMetric `@@unique([studentId, sessionId])`，sessionId 可空
- Event/Communication 通过 sessionId 绑定课次

## 2. 表结构详情

### 2.0 Class（v0.10 新增）

```prisma
model Class {
  id    String  @id @default(cuid())
  code  String  @unique   // 班级编号 "G3-01"，必填
  name  String?           // 班级名称 "高三(1)班"，可空

  students Student[]
  sessions ClassSession[]
}
```

### 2.0b Label / StudentLabel（v0.13 新增）

```prisma
model Label {
  id   String @id @default(cuid())
  name String @unique
  students StudentLabel[]
}

model StudentLabel {
  studentId String
  labelId   String
  student Student @relation(fields: [studentId], references: [id], onDelete: Cascade)
  label   Label   @relation(fields: [labelId], references: [id], onDelete: Cascade)
  @@unique([studentId, labelId])
  @@index([studentId])
  @@index([labelId])
}
```

### 2.10 SystemLog (v0.11)

```prisma
model SystemLog {
  id         String   @id @default(cuid())
  action     String   // "score.updated" | "alert.triggered" | "student.deleted" | ...
  targetType String   // "Student" | "Session" | "Draft" | "Class" | "System"
  targetId   String?  // 关联实体 id
  targetName String?  // 冗余字段，便于前端展示
  detail     String   @default("{}") // JSON
  createdAt  DateTime @default(now())
}
```

| # | 已知问题 | 状态 |

| SL1 | 无唯一约束 | 特性，同操作允许重复 |

### 2.11 WorkHistory (v0.14)

```prisma
model WorkHistory {
  id        String   @id @default(cuid())
  module    String
  key       String?
  title     String
  state     String   // JSON 页面快照
  createdAt DateTime @default(now())

  @@index([module, createdAt])
  @@index([module, key, createdAt])
}
```

历史默认长期保存，仅由用户在页面历史面板中单条删除或按模块清空。`state` 只用于恢复页面状态，不会在恢复时自动写入评分、考勤等业务表。
