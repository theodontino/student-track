## 1. 系统架构

```
前端 (Next.js App Router)
  11 个页面 · 全部 "use client"
        │  fetch() / SSE
        ▼
API 层 (Route Handlers)
  19 个路由文件（含 ?stream=true 流式模式）
        │  Prisma Client
        ▼
SQLite (libsql) · 14 张表
        │
        ▼
外部 LLM (DeepSeek · OpenAI SDK)
  correctNamesWithLLM → parseInput → reviewParsed（3 轮 LLM 调用）
```

**关键依赖链**:
- 页面 → `fetch(/api/...)` → Route Handler → `@/lib/prisma` → SQLite
- NL 录入 → `lib/parser.ts` → `lib/prompts.ts` → `lib/llm.ts` → DeepSeek

## 2. 数据模型摘要

```
Label ←── StudentLabel ──→ Student
                    ↑
Class ──< Student ──< Attendance >── ClassSession ──< Semester
                                      │
                                      ├──< SessionMetric
                                      ├──< Event
                                      └──< Communication

SessionMetricHistory (追加归档，含索引)
DraftRecord (独立表，含 studentId/sessionCode)
SystemLog (操作日志)
WorkHistory (长期工作状态快照)
```

| 表 | 唯一约束 | 说明 |
|---|---|---|
| Class | `code @unique` | v0.10: 班级独立表 |
| Label | `name @unique` | v0.13: 标签库 |
| StudentLabel | `@@unique([studentId, labelId])` | v0.13: 多对多关联 |
| Student | `studentId @unique` | 基础档案 |
| SessionMetric | `@@unique([studentId, sessionId])` | 每课次独立评分，sessionId 可空 |
| Event | `@@unique([studentId, sessionId, description])` | 关键事件，绑定 sessionId |
| Communication | — | 家校沟通，绑定 sessionId |
| DraftRecord | — | NL 待复核草案 |
| Semester | — | 学期管理 |
| ClassSession | `code @unique` (YYYYMMDDNN) | 课次编码体系 |
| Attendance | `@@unique([sessionId, studentId])` | 考勤记录 |
| SessionMetricHistory | 追加 + `@@index([studentId])` / `@@index([metricId])` | 评分变更归档 |
| SystemLog | 追加模式 | 操作日志，90 天清理 |
| WorkHistory | `@@index([module, createdAt])` | 页面快照，长期保存、用户主动清理 |

> 完整字段、已知问题、优化路线见 **[数据结构](数据结构.md)**。

## 4. 核心业务规则

### 4.1 评分维度

| 维度 | 名称 | 打分方 | 范围 |
|---|---|---|---|
| A | 学习目标达成 & 课堂测验 | 教师 / LLM | 0-5 |
| B | 精神面貌 & 课堂纪律 | 教师 / LLM | 0-5 |
| C | 课后任务 | 教师 / LLM | 0-5 |
| D | 考勤 | 系统自动计算 | 0-5 |

### 4.2 考勤公式

```
D = ROUND(5 × 出勤次数 / 当前学期总课次数)
```

- **重算时机**: 创建课次后、考勤变更后、删除课次后
- **当前学期判定**: `startDate ≤ today ≤ endDate`

### 4.3 预警规则

**班级预警**：班级人数 ≥ 5 时生效

| 条件 | 等级 |
|------|------|
| 班级任一门 (A/B/C) 均分 < 2.5 | 🔴 红色 |
| 班级任一门 (A/B/C) 均分 < 3.0 | 🟡 黄色 |

**学生预警**：每维度独立计算 `deviation = 学生得分 − 班级均分`，取 deviation < 0 的学生按升序排名

| 等级 | 排名区间 |
|------|---------|
| 🔴 红色 | 后 0% ~ 10%（含并列） |
| 🟡 黄色 | 后 10% ~ 20%（含并列） |

**D 维度（考勤）**：独立规则，不参与班级均分和学生排名

| 条件 | 等级 |
|------|------|
| 当前学期缺勤 ≥ 4 次 | 🔴 红色 |
| 当前学期缺勤 ≥ 2 次 | 🟡 黄色 |

> 无评分数据的学生不纳入预警。同学生同维度只保留最严重级别。

### 4.4 课次编码体系

`YYYYMMDDNN` 全局唯一编码：
- `date` 字段从编码推导（`code.slice(0.8)`），冗余存储方便索引
- 同天可多课次（不同班级），靠 NN 序号区分
- API 标识用编码：`/api/sessions/2026060401`
- 学期内序号 `semesterNumber` 在增删课次后自动重排

### 4.5 NL 处理链（v0.13: 3 轮 LLM）

```
教师文本
  → ① correctNamesWithLLM(temp=0.1): 姓名纠错（同音/形近/简写）
     → 返回 { correctedText, corrections[{ original, corrected, confidence, reason }] }
  → ② parseInput(temp=0.3): 实体识别 + 打分 + 事件提取
     → 支持 ?stream=true SSE 流式输出 token
  → ③ reviewParsed(temp=0.2): 逻辑自审 + 修正建议
     → 含 name_issues（人名/事件对应问题 + severity）
  → 按所选课次班级花名册补齐：提及学生 present=true，未提及学生 present=false
  → 保存 DraftRecord(status=pending)
  → 教师复核: 修改分数/删除事件 → 确认/放弃
     → 确认时前端高亮展示姓名修正和 confidence 标签
  → 确认时: SessionMetric upsert + Event create + Communication create
```

**约束**:
- LLM 只输出文本中提及的学生；服务端补齐同班未提及学生并标记缺勤
- NL 录入必须选择有关联班级的课次
- 未提及的维度 score 为 `null`
- D 不由 LLM 打分
- LLM 姓名纠错: 发音相似/字形相近/简写口语化/缺姓氏 → 修正，无法确定则保持原样
- LLM 调用最多 2 次重试（v0.6）

### 4.6 数据写入规则

| 实体 | 写入方式 | 说明 |
|---|---|---|
| SessionMetric | upsert (studentId + sessionId) | 有课次时按 sessionId 精确 upsert；无课次时 sessionId=null，同天仅保留一条 |
| Event | 追加 create | 必须绑定 sessionId，日期从 ClassSession.date 获取 |
| Communication | 追加 create | 同上 |
| scoreD | update 最新 metric | 不创建 A/B/C=0 的新行 |
| SessionMetricHistory | 追加 create | 评分更新前自动归档旧值 |

### 4.7 学生姓名模糊匹配（v0.5）

4 级匹配策略：精确匹配 → 去后缀 → 子串匹配 → 字符重叠度

解析阶段自动调用 `correctNames()`，将 LLM 输出的姓名修正为数据库中的标准姓名。

## 5. API 参考

### 5.1 学生管理

| 方法 | 路由 | 功能 |
|---|---|---|
| GET | `/api/students` | 学生列表（可按班级筛选） |
| POST | `/api/students` | 创建学生 |
| GET | `/api/students/[id]` | 学生详情（含 365 天 metrics + events + communications） |
| PUT | `/api/students/[id]` | 更新学生信息 |
| DELETE | `/api/students/[id]` | 删除学生（级联删除关联数据） |
| GET | `/api/students/[id]/history` | 评分变更历史 |
| POST | `/api/students/import` | Excel 批量导入花名册 |

### 5.2 NL 处理

| 方法 | 路由 | 功能 |
|---|---|---|
| POST | `/api/input/parse` | NL 文本解析 + LLM 自审 + 整班缺勤补齐 → 保存 DraftRecord |
| POST | `/api/input/parse?stream=true` | SSE 流式解析（逐 token 输出），含姓名纠错修正 |
| GET | `/api/review` | 草案列表（可按状态/班级筛选） |
| POST | `/api/review` | 确认写入 / 放弃草案 |

### 5.3 快速评分

| 方法 | 路由 | 功能 |
|---|---|---|
| GET | `/api/quick-score` | 按课次查询已有评分 + 考勤 |
| POST | `/api/quick-score` | 批量提交评分 + 考勤 + 重算 D（sessionCode 无效时返回 404） |

### 5.4 仪表盘

| 方法 | 路由 | 功能 |
|---|---|---|
| GET | `/api/alerts` | 概览卡片 + 预警列表 + 班级四维平均 |

### 5.5 考勤

| 方法 | 路由 | 功能 |
|---|---|---|
| GET | `/api/attendance` | 按课次/学期查询考勤 |
| PUT | `/api/attendance` | 批量更新考勤 + 重算 D |

### 5.6 学期与课次

| 方法 | 路由 | 功能 |
|---|---|---|
| GET | `/api/semesters` | 学期列表 |
| POST | `/api/semesters` | 创建学期 |
